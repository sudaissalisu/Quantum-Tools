# **App Name**: QRGenius

## Core Features:

- QR Code Generation: Generate QR codes for URLs, text, Wi-Fi credentials, and contact information (vCard) directly in the browser.
- Real-time Preview: Display the QR code instantly as the user types in the input fields.
- Data Privacy: Ensure all QR codes are generated locally, and the data never leaves the user's browser.
- High-Quality Download: Allow users to download the generated QR code as a high-quality .png or .svg file.
- Support Widget: A 'Buy Me a Coffee' widget is shown in the corner or under the download button, with the message: 'Enjoying this free, no-ads tool? Please consider supporting its development!'

## Style Guidelines:

- Primary color: A calming blue (#468189), associated with trust and privacy.
- Background color: Light gray (#D6DDE1), almost white, offering a clean and simple appearance.
- Accent color: Muted teal (#67A9A4), providing subtle highlights without being too intrusive.
- Body and headline font: 'Inter' for a modern, objective feel. 
- Use simple, monochrome icons for each QR code type (URL, Text, Wi-Fi, Contact).
- Tabbed interface for different QR code types with input fields on the left and QR code preview on the right.
- Subtle animation on the 'Download' button to provide visual feedback.
